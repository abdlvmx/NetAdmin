Для администратора сети

Настроить сервер

Создайте панель управления компьютерами. Сервер нужен на одном компьютере, который будет доступен остальным.

Установить для постоянной работы

Сервер будет запускаться вместе с Windows и работать после закрытия окна. Windows запросит права администратора.

{{if not .CanInstall}}

Установка службы доступна в Windows.

{{end}}
Для компьютера сотрудника

Подключить этот компьютер

Если сервер уже есть, установите агент. Он передаёт состояние этого компьютера в панель администратора.

Что понадобится?

Попросите администратора прислать подготовленный агент. Или получите адрес сервера и код подключения: установка спросит их в отдельном окне.

{{if not .CanAgent}}

Нужен готовый комплект Windows или подготовленный файл агента от администратора.

{{end}}

Демо временное. При запуске сейчас сервер работает, пока окно NetAdmin открыто, и сохраняет данные в папке программы. Для постоянной работы лучше сразу выбрать установку сервера: последующий переход потребует ручного переноса данных.

{{end}}
