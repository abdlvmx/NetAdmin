# Первый запуск NetAdmin

NetAdmin помогает учитывать компьютеры, следить за их состоянием и обрабатывать
заявки. Для знакомства достаточно одного Windows-ПК; для работы с сетью сервер
устанавливается на одном компьютере, а агенты — на остальных.

## Скачать и открыть

1. [Скачайте комплект для Windows](https://github.com/abdlvmx/NetAdmin/releases/latest/download/NetAdmin-Windows-x64.zip).
2. Щёлкните ZIP правой кнопкой и выберите **«Извлечь всё»**.
3. Откройте **netadmin.exe** двойным щелчком. Мастер откроется в браузере.

В комплекте уже есть всё необходимое. Установка Go и сборка исходного кода нужны
только разработчикам. Кнопка GitHub **Code → Download ZIP** скачивает исходники;
готовая программа находится по ссылке выше и в разделе **Releases**.

## Выбрать, с чего начать

| Что вы хотите сделать | Что выбрать |
|---|---|
| Посмотреть возможности без настройки сети | **Посмотреть демо** |
| Управлять компьютерами своей организации | **Настроить сервер** |
| Добавить этот ПК к уже работающему серверу | **Подключить этот компьютер** |

**Демо** показывает вымышленные устройства, сотрудников и заявки. Вход:
`admin` / `Parol12345`. Данные временные, сеть не сканируется, письма не
отправляются. Пока смотрите демо, оставьте окно NetAdmin открытым.

**Сервер** достаточно установить на одном ПК. Выберите компьютер, который будет
включён в нужное вам время. В мастере нажмите **«Установить для постоянной работы»**:
после установки службы откроется панель для создания администратора. Запрос прав
появится через обычное окно Windows. После установки служба работает независимо
от открытого окна программы.

Для запуска без установки службы доступно **«Запустить сейчас»**. В этом режиме
сервер работает, пока открыто окно NetAdmin. Этот вариант удобен для знакомства
с настройкой; для постоянной работы используйте установку службы.

**Подключение ПК** предназначено для тех, у кого уже есть сервер. Потребуются его
адрес и код подключения от администратора. Мастер поможет запустить агент;
в обычном `agent.exe` адрес и код вводятся в окне установки. Если администратор
выдал готовый файл агента, откройте именно его: данные подключения уже заполнены.

## Подключить другие компьютеры

В панели сервера откройте **Настройки**, создайте код подключения и нажмите
**«Скачать готовый файл»**. Передайте файл на нужный компьютер и откройте его
двойным щелчком. Установщик запросит права Windows и проверит передачу данных
серверу. Когда установка подтвердится, компьютер появится в разделе **Устройства**.

Обычный `agent.exe` из комплекта предназначен для подключения с ручным вводом
адреса и кода. Создавать новый сервер на каждом компьютере не требуется.

## Вернуться в панель

Используйте ярлык NetAdmin или адрес, показанный после установки. По умолчанию на
серверном компьютере это [http://127.0.0.1:8765](http://127.0.0.1:8765).
На другом ПК используйте сетевой адрес сервера, например `http://192.168.1.10:8765`.

Если браузер не открылся автоматически, скопируйте показанный программой адрес в
его адресную строку. При ошибке подключения агента проверьте, что сервер включён,
адрес введён правильно, а срок действия кода ещё не истёк.

## Обновить сервер

Скачайте новый комплект, извлеките его в отдельную папку и откройте новый
`netadmin.exe`. Выберите **«Настроить сервер»**, затем
**«Установить для постоянной работы»**. Установщик сохранит данные и проверит новую
версию; при ошибке вернёт прежнюю установку.

Данные установленного сервера находятся в `C:\ProgramData\NetAdmin`. Удалять эту
папку для обновления не нужно. Подробности обновления, резервного копирования
и переноса — в [руководстве по развёртыванию](deploy.md) и
[руководстве по эксплуатации](operations.md).
