NetAdmin — начните здесь
=======================

1. Извлеките все файлы из ZIP в обычную папку.
   Откройте netadmin.exe двойным щелчком.
   Для запуска не нужно устанавливать Go, Python или базу данных.

2. В открывшемся мастере выберите нужное действие:

   ПОСМОТРЕТЬ ДЕМО
   Познакомиться с панелью на вымышленных устройствах и заявках.
   Вход: admin / Parol12345.
   Демо использует временную базу, не сканирует сеть и не отправляет письма.
   Пока смотрите демо, оставьте окно NetAdmin открытым.

   НАСТРОИТЬ СЕРВЕР
   Управлять своими компьютерами. Сервер достаточно установить на одном ПК,
   который будет включён, пока требуется мониторинг сети.
   Выберите «Установить для постоянной работы», подтвердите запрос Windows
   на права администратора и создайте свою учётную запись в панели.
   Служба запускается автоматически. «Запустить сейчас» позволяет работать
   без установки службы; в этом режиме окно NetAdmin должно оставаться открытым.

   ПОДКЛЮЧИТЬ ЭТОТ КОМПЬЮТЕР
   Добавить ПК к уже работающему серверу. Потребуются адрес сервера и код,
   которые выдаёт администратор. Мастер подскажет, как запустить агент.
   В обычном agent.exe адрес и код вводятся в окне установки. Если у вас
   готовый агент с сервера, запустите его двойным щелчком: данные уже заполнены.

3. Добавляйте остальные компьютеры через раздел «Настройки» панели:
   создайте код подключения и скачайте готовый агент. Запустите этот файл
   на нужном ПК и подтвердите запрос Windows. Установщик проверит, что сервер
   принял данные, и сообщит результат подключения.

Что находится в комплекте
------------------------
netadmin.exe       Сервер, веб-панель и мастер первого запуска.
agent.exe          Агент без заранее заполненных адреса и кода подключения.
                   Если вы знакомитесь с программой, начните с netadmin.exe.
SHA256SUMS.txt      Контрольные суммы двух EXE.
START-HERE.txt      Эта инструкция.

Как открыть панель снова
-----------------------
Используйте ярлык NetAdmin, созданный установщиком, или адрес панели,
показанный после установки. По умолчанию на серверном ПК:
http://127.0.0.1:8765

Обновление
----------
Скачайте свежий комплект, извлеките его в отдельную папку и запустите новый
netadmin.exe. Выберите настройку сервера и «Установить для постоянной работы».
Установщик сохранит текущие данные
и вернёт прежнюю установку, если новая версия не пройдёт проверку.
Не удаляйте C:\ProgramData\NetAdmin: там находятся данные вашей установки.
